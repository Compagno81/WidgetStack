# Navigation changes in 1.5

In Edit stack, open Customize navigation bar and turn on Overlap widget. The displayed widget keeps the full stack area and the bar sits over its chosen edge. The bar continues to use its configured position, thickness and opacity. Both the normal dots-and-buttons mode and Buttons only are supported.

Taps and gestures on the covered bar area go to the bar. Use a narrow width or a different edge if the bar covers controls you need in a widget. Touches outside the bar keep their normal widget handling.

Overlap is saved separately for each stack and defaults off for existing stacks. The visual editor shows changes before Apply; Cancel retains the saved setting. Turning overlap off reserves space next to the widget as before. No system overlay permission is needed.
