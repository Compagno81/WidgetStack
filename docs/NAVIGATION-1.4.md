# Navigation changes in 1.4

Open a stack in Widget Stack and choose Customize navigation bar. Turn on Buttons only to show just previous and next: each button fills half the bar. The dots and settings gear are hidden in this mode. Open the app's stack list to edit it later. Turning the mode off restores the dots, settings gear and quarter-length end buttons.

Bar thickness now ranges from 8 to 80 dp on any edge. Control glyphs scale with thickness, and the preview responds live. Thin settings also make the touch area narrow; select the size that works on your screen. Each stack retains independent mode, thickness, opacity, edge and animation settings. Existing stacks keep their saved settings and start with Buttons only off.

The picker refreshes on reopening or through its Refresh menu action. App, widget and package names are searchable, including spaced names such as Duo Lingo and My Fitness Pal. Visibility declarations have been expanded to address missing apps. The user's actual Duolingo and MyFitnessPal versions still need a device check. If either is absent, open that app once, refresh, and check whether the stock launcher lists its widgets.

Version 1.3's optional tap-triggered slide-in effect remains available. Dragging to switch widgets is not introduced.
