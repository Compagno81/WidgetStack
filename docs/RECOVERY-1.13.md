# Widget Stack 1.13

The widget editor now displays compact ↑ and ↓ reorder controls instead of wrapping “Move up” and “Move down” across multiple lines. Screen readers retain the accessible names “Move up” and “Move down”. Setup and Remove actions are single-line compact buttons. The app's scrollable screens now clip to their system-bar padding so the page heading does not draw beneath the status bar.

Verification: 181 unit-test executions passed with zero failures or errors; lint passed; the version 1.13 debug APK was built and its version and established debug signing certificate were verified. Physical-device visual verification remains outstanding.
