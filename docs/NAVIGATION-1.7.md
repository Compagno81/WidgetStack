# Navigation changes in 1.7

Open Edit stack, then Customize navigation bar, Behaviour. Enable Auto-contract. Enter the delay in whole seconds, 2 or more; the default remains 2 seconds. Blank, fractional, overflowing and below-minimum input cannot be applied. There is no arbitrary 60-second limit. Each navigation tap restarts the saved per-stack delay. Provider updates and touches within hosted content do not restart it.

Choose Edge strip or Corner square. The contracted-size slider controls strip thickness or the square side length, from 4 dp to one dp below expanded thickness. Increase expanded thickness first if a larger corner target is desired. For the square, choose Top / left or Bottom / right along the selected edge. For example, a right-edge bar offers top-right and bottom-right. A plus mark appears for squares at least 12 dp wide. The square always sits over the content; the rest of the widget, including the rest of that edge, remains interactive. Expanded mode still respects the separate Overlap widget preference.

Tap the contracted target to expand without changing widget selection. Both directions animate over 240 ms with easing: the strip slides towards the selected edge; the square mode scales the bar length towards its chosen corner while retaining a stationary square. Animations execute in the launcher using standard RemoteViews-supported ViewFlipper and XML animations, without frame-by-frame binder updates, screenshot substitution, overlays or repeating alarms. Latest provider snapshots are rendered after an in-flight bar animation settles. A new navigation action cancels the older timer and settle callbacks.

Android cannot animate the third-party provider's responsive layout continuously through RemoteViews. With Overlap widget off, content reflows at expansion start and contraction completion; this reflow is a discrete size change. With overlap on, the widget keeps its full size throughout. Animation timing can be delayed by launcher load, sleep, process termination or OEM battery policy. Process restart begins contracted. Pixel and HyperOS launcher appearance/timing still require physical-device testing.

The preview uses the same transition layouts and delay, and restricts bar gestures to the actual contracted square when square mode is selected. A parent touch shield consumes provider clicks, scrolls and long presses, and provider descendants are excluded from accessibility and keyboard focus. Stack controls remain active through local hit testing; no provider PendingIntent is sent from preview gestures. It reuses cached live provider content; launcher-specific padding, rounding and theme treatment can differ.
